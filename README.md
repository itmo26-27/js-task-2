# Задание 2. JavaScript: клонирование объектов с сохранением поведения

Задание к лекции [«Прототипы»](https://itmo-frontend-lectures.vercel.app/1-sem/js/4-prototype/index.html).

**Дедлайн для получения полного балла — 25 ноября 2026 года включительно.**

Реализуйте функцию `cloneGraph(value)`, которая создаёт независимую копию графа объектов, сохраняя его структуру, прототипы и свойства.

Поддерживаются примитивы, массивы и объекты, включая объекты с пользовательским или отсутствующим прототипом. Функции сохраняются по ссылке. Поддержка `Date`, `Map`, `Set`, DOM-объектов и экземпляров с приватными полями не требуется.

## Как должна работать функция

- Изменение собственного вложенного объекта в копии не меняет оригинал.
- Если два свойства оригинала указывают на один объект, соответствующие свойства копии указывают на одну общую копию этого объекта.
- Циклические ссылки сохраняются. Если объект ссылается на себя, его копия ссылается на себя.
- Каждый скопированный объект сохраняет исходный прототип по ссылке. Унаследованные свойства не становятся собственными. Изменение общего прототипа после клонирования видно и оригиналу, и копии.
- Сохраняются все собственные свойства: строковые, символьные и неперечисляемые. Сохраняются ограничения на запись, удаление и перечисление.
- Геттеры и сеттеры переносятся без вызова. Даже геттер, который выбрасывает ошибку, не мешает клонированию. При последующем обращении к свойству копии аксессор получает копию как `this`.
- У массивов сохраняются длина, дополнительные свойства и пропуски между элементами. Пропущенный элемент и элемент со значением `undefined` должны оставаться различимыми.
- Конструкторы не вызываются. Оригинальные объекты, их прототипы и встроенные прототипы не изменяются.

Использовать готовое клонирование, преобразование через JSON и сторонние библиотеки нельзя.

## Обязательная сложная проверка

Соберите один граф, в котором одновременно есть цикл, несколько ссылок на общий объект, массив с пропусками, символьное свойство, неперечисляемое неизменяемое свойство и геттер, выбрасывающий ошибку. Функция должна корректно скопировать весь граф, а не только проходить отдельные простые примеры.

## Что сдать

Реализацию, проверки с ожидаемыми результатами и объяснение того, какие связи копируются, какие сохраняются и почему.
