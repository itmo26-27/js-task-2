# Решение
Функция `cloneGraph` создаёт независимую копию графа объектов

## Циклы и общие ссылки
Для уже обработанных объектов используется `WeakMap`
Перед копированием свойств новая копия записывается в `WeakMap` 
Поэтому циклическая ссылка получает уже созданный объект, а несколько ссылок на один объект продолжают указывать на одну общую копию

## Прототипы
Обычный объект создаётся через `Object.create` с исходным прототипом 
Для массива создаётся новый массив, после чего ему назначается исходный прототип
Конструкторы при этом не вызываются
Сам прототип не копируется, поэтому его последующие изменения видны и оригиналу, и копии

## Свойства
`Reflect.ownKeys` возвращает все собственные ключи, включая неперечисляемые и символьные
Для каждого ключа функция отдельно получает дескриптор через `Object.getOwnPropertyDescriptor`
У свойства-данных рекурсивно копируется значение, после чего свойство переносится через `Object.defineProperty` со всеми исходными ограничениями

Геттеры и сеттеры не вызываются во время клонирования, потому что функция работает с дескрипторами и не читает значение аксессорного свойства
После переноса геттер вызывается уже у копии, поэтому `this` указывает на копию

## Массивы и функции
У массива копируются только существующие собственные свойства
Поэтому пропуск между элементами не превращается в элемент со значением `undefined`
Также сохраняются `length` и дополнительные свойства массива
Функции не клонируются и остаются по исходной ссылке

## Проверка
В `index.js` собран один сложный граф, в котором одновременно находятся цикл, две ссылки на общий объект, разреженный массив, символьное свойство, неперечисляемое неизменяемое свойство и геттер, который выбрасывает ошибку
Также проверяются независимость копии, сохранение прототипов и отсутствие повторного вызова конструктора
