# Ответы на задание 2

## Идея решения

Клонирование — это обход графа объектов. Для каждого встреченного объекта создаётся пустая оболочка с тем же прототипом, после чего в неё переносятся дескрипторы собственных свойств. Соответствие «оригинал → копия» хранится в `Map` `seen`.

`Map` решает сразу две задачи:

- **циклы**: объект попадает в `Map` до обхода его свойств, поэтому ссылка на самого себя возвращает уже созданную копию;
- **общие ссылки**: все свойства, указывающие на один и тот же объект, получают один и тот же клон, а не независимые копии.

Примитивы и функции сразу возвращаются как есть. Примитивы неизменяемы, а функции по условию должны сохраняться по ссылке. Поэтому функции не клонируются, даже если у них есть собственные свойства.

## Создание копии объекта

Для массива создаётся настоящий массив `[]`, для остальных объектов — `Object.create(proto)`, где `proto` получен через `Object.getPrototypeOf`. Прототип передаётся по ссылке, а не копируется. Для массива прототип дополнительно выставляется явно, чтобы поддержать массивы с пользовательским прототипом. Конструкторы при этом не вызываются.

## Перенос свойств

`Object.getOwnPropertyDescriptors(value)` возвращает дескрипторы **всех** собственных свойств: строковых и символьных, перечисляемых и неперечисляемых. Для каждого дескриптора с полем `value` значение рекурсивно клонируется. Дескрипторы доступа (`get`/`set`) остаются без изменений.

Затем `Object.defineProperties(copy, descriptors)` создаёт свойства копии с теми же флагами `writable`, `enumerable` и `configurable`. Этот способ:

- не вызывает геттеры и сеттеры;
- не идёт по цепочке прототипов, поэтому унаследованные свойства не становятся собственными;
- сохраняет ограничения на запись, удаление и перечисление;
- не вызывает сеттеры, даже если они есть в оригинале или его прототипе.

Геттер — это обычная функция, поэтому он переносится по ссылке и не вызывается при клонировании. При последующем чтении `copy.x` JavaScript вызывает его с `this`, равным `copy`. Например, геттер `get self() { return this; }` вернёт именно копию. Геттер, который выбрасывает ошибку, не мешает клонированию: ошибка возникнет только при обращении к свойству копии.

## Массивы

Массив остаётся массивом. Переносятся все его собственные свойства, включая `length` и дополнительные строковые или символьные свойства.

- **Пропуск** — это отсутствие собственного свойства с данным индексом, поэтому пропуск остаётся пропуском.
- **Явно записанный `undefined`** — это собственное свойство со значением `undefined`, поэтому оно остаётся собственным и отличимым от пропуска.
- **`length`** переносится как дескриптор, поэтому сохраняются хвостовые пропуски и нестандартная длина. Индексы определяются раньше `length`, что важно для массива с `length`, недоступным для записи.

## Что копируется, а что остаётся общим

| Сущность                            | В копии                                                                |
| ----------------------------------- | ---------------------------------------------------------------------- |
| Примитивы                           | То же значение                                                         |
| Функции                             | Та же ссылка                                                           |
| Прототипы объектов                  | Та же ссылка                                                           |
| Функции геттеров и сеттеров         | Та же ссылка                                                           |
| Значения обычных свойств-объектов   | Новые копии                                                            |
| Дескрипторы свойств                 | Скопированы с теми же флагами                                          |
| Пропуски в массивах                 | Сохранены                                                              |
| Циклы и общие ссылки                | Одна общая копия на объект                                             |
| Нерасширяемость (`frozen`/`sealed`) | Сохранена: после определения свойств копия тоже делается нерасширяемой |

Поскольку прототип общий, его последующее изменение видно и оригиналу, и копии. Поскольку функции общие, их собственные свойства также остаются общими — это следствие требования «функции сохраняются по ссылке».

## Почему не JSON, spread и готовое клонирование

JSON теряет прототипы, символьные и неперечисляемые свойства, дескрипторы, пропуски в массивах, `undefined`, циклы и общие ссылки. `Object.assign` и spread читают значения через `[[Get]]`, поэтому вызывают геттеры и не сохраняют дескрипторы. `structuredClone` сохраняет циклы, но не переносит прототипы и дескрипторы, а его использование как готового клонирования запрещено условием. Поэтому нужен ручной обход с переносом дескрипторов.

## Сложность

Время — `O(n + p)`, где `n` — число объектов графа, `p` — суммарное число собственных свойств. Память — `O(n)` для `Map` и самих копий; глубина рекурсии равна глубине графа.
