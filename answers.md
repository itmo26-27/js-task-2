# Объяснение решения

1. `cloneGraph` создаёт новые объекты для значений собственных свойств. Вложенные объекты тоже копируются, поэтому их изменение в копии не меняет оригинал. Примитивы возвращаются как есть. Функции сохраняются по ссылке.

2. В `WeakMap` хранится соответствие между исходным объектом и его копией. Копия добавляется туда до обхода свойств. При повторной встрече объекта возвращается уже созданная копия. Так сохраняются циклы и общие ссылки. Для каждого вызова `cloneGraph` создаётся отдельная таблица.

3. Прототип сохраняется по ссылке через `Object.getPrototypeOf` и `Object.create`. У массивов создаётся настоящий массив. Затем ему устанавливается исходный прототип. Конструктор исходного объекта не вызывается. Унаследованные свойства не копируются, поэтому остаются унаследованными. Изменения общего прототипа видны оригиналу и копии. Прототип `null` тоже сохраняется.

4. `Reflect.ownKeys` возвращает все собственные ключи, включая символы и неперечисляемые свойства. Свойства читаются через дескрипторы и создаются через `Object.defineProperty`. Сохраняются `writable`, `enumerable` и `configurable`. У свойства с данными копируется значение, а геттер и сеттер переносятся по ссылке без вызова. При обращении через копию они получают копию как `this`.

5. У массива копируются только существующие собственные свойства, поэтому пропуски не превращаются в элементы со значением `undefined`. Свойство `length` сохраняет длину, в том числе пропуски в конце. Числовые ключи обрабатываются перед `length`, поэтому неизменяемая длина устанавливается после элементов. Дополнительные свойства копируются тем же способом.

6. Функция изменяет только новые объекты и дескрипторы, полученные для копирования. Оригинальные объекты и их прототипы не меняются. Готовое клонирование, JSON и сторонние библиотеки не используются.

# Проверки

Запуск: `node checks.js`. 

Ожидаемые значения указаны в проверках `assert`. При успешном выполнении вывод отсутствует, при несовпадении возникает ошибка.

В одном графе проверяются цикл, общий вложенный объект, массив с пропусками и явным `undefined`, символьное свойство, неперечисляемое неизменяемое свойство и геттер с ошибкой. Дополнительно проверяются независимость копии, дескрипторы, работа аксессоров с `this`, общий прототип, функции по ссылке, примитивы, объект без прототипа, массив с пользовательским прототипом и отсутствие повторного вызова конструктора.
